# 多维权衡矩阵模板 · 选型对比

> 用途：为 ADR 的 `options` 提供显式、可复核的多维对比；结论回填 ADR 的 `options` / `decision`。
> 本模板本身不机检；其结论须落入 `schemas/adr.schema.json` 方可过门控。
> 维度可依场景增删，但增删后须在本矩阵内显式声明。
> 所有图谱节点 id 须先在 `<MISSION_ROOT>/10-dag-data/methodology-dag.json` 中核实存在。

## 一、维度定义

| 维度 | 含义 | 典型度量 | 可否增删 |
|---|---|---|---|
| 功能匹配度 | 方案满足核心需求的程度 | 需求覆盖项数 / 缺失项 | 保留 |
| 成本 | 一次性成本 + 持续成本（运维、认知） | 人日 / 月运维量 | 保留 |
| 风险 | 技术与交付风险 | 高/中/低，或发生概率 × 影响 | 保留 |
| 可演化性 | 应对未来变化的能力 | 变更波及模块数 | 保留 |
| 可扩展性 | 按需伸缩能力 | 扩容成本 | 按场景增删 |
| 团队适配 | 与团队认知负荷 / 技能的匹配度 | 学习曲线人日 | 按场景增删 |

> 增删规则：仅保留对本决策**有区分度**的维度；无区分度的维度会稀释权重，应删除或说明保留理由。

## 二、权重与评分口径

- **权重**：每个维度赋权重 `w_i`，全部维度权重之和归一化为 `1.0`（或 100%）。
- **评分**：每个方案在每个维度打 `1–5` 分（5 最优），且**须给出评分依据**（不能只给数字）。
- **加权得分**：`S(方案) = Σ (w_i × score_i)`。
- **否决项**：若某维度存在硬约束（如"不可引入分布式复杂性"），设为否决项；不满足即淘汰，
  不进入加权计算，并在结论中说明。

## 三、填表示例

| 维度 | 权重 | 方案A 模块化单体 | 方案B 按服务拆分 |
|---|---:|---:|---:|
| 功能匹配度 | 0.20 | 4 | 4 |
| 成本（含持续成本） | 0.30 | 5 | 2 |
| 风险 | 0.20 | 4 | 2 |
| 可演化性 | 0.20 | 3 | 5 |
| 团队适配 | 0.10 | 5 | 2 |
| **加权得分** | **1.00** | **4.20** | **3.00** |

**加权计算过程**：

- 方案A = 0.20×4 + 0.30×5 + 0.20×4 + 0.20×3 + 0.10×5 = 0.8 + 1.5 + 0.8 + 0.6 + 0.5 = **4.20**
- 方案B = 0.20×4 + 0.30×2 + 0.20×2 + 0.20×5 + 0.10×2 = 0.8 + 0.6 + 0.4 + 1.0 + 0.2 = **3.00**

**评分依据**：

| 维度 | 方案A 评分依据 | 方案B 评分依据 |
|---|---|---|
| 功能匹配度 | 需求均可覆盖，无明显缺失 | 需求均可覆盖，无明显缺失 |
| 成本 | 单部署单元，运维与认知成本低 | 分布式运维、链路追踪等持续成本高 |
| 风险 | 技术栈熟悉，交付风险低 | 一致性/可观测性风险高 |
| 可演化性 | 边界靠纪律维持，演进受限 | 服务边界天然支持独立演进 |
| 团队适配 | 与 5 人团队认知负荷匹配 | 需要平台与 SRE 能力，超出承载 |

> 示例中的权重与评分仅为示范，实际取值必须来自场景约束与干系人共识，并随 ADR 留档。

## 四、结论与 ADR 的衔接

1. **得分高者不必然是最终决策**：须结合否决项以及 ADR 中的 `sensitive_points` / `tradeoff_points`
   复核后再定。
2. **回填 ADR**：
   - `options[]`：每个候选对应矩阵中一列（`name` / `description` / `pros[]` / `cons[]`）。
   - `decision`：选定方案 + 关键理由（不得推荐具体技术、禁 `TEC-` id）。
   - `rationale`：引用矩阵中权重最高维度所对应的图谱节点，如权衡方法 `MTH-M-06`、
     本质判据 `ESS-O-02`（节点 id 须核实存在）。
   - `tradeoff_points[]`：矩阵中分数差距最大或牵制最明显的维度。
3. **留档**：矩阵的权重与评分依据应随 ADR 一并留档，便于复核与回退。
4. 技术实践层节点（`TEC-`）如需引用，只能进入 ADR 的 `standards_refs`，且须字面精确命中场景。
