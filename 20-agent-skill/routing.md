## A. 决策与选型

### 1. 为绿地项目做技术选型
- 触发问法：选框架/风格/组件、要不要上微服务、够不够用、会不会过度设计。
- 应读节点：`MTH-O-03` 够用原则 → `MTH-O-04` 能力-成本-速度三角 → `MTH-O-08` 复杂度阶梯 → `MTH-G-03` 架构风格选择 → `ESS-G-05` 架构风格本质。
- 组/视图：GD-O 方法论主干；决策矩阵 03；技术雷达 `TEC-G-04`。
- 学习路径：方法论层 O 域段（`02-learning-path.html` §3）。
- 案例：`CAS-X-12` MCP 四件套选型对比、`CAS-X-02` 零依赖零构建选型。

### 2. 为遗留系统定重构优先级
- 触发问法：老系统怎么改、先重写还是先加测试、重构从哪下手。
- 应读节点：`MTH-L-06` 遗留系统渐进治理 → `MTH-L-02` 代码坏味道启发式 → `MTH-L-03` 技术债象限与偿还 → `MTH-L-01` 行为保持重构 → `ESS-L-02` 技术债本质。
- 组/视图：GD-L 演化与弃用；分层层 `ESS-L-03` 架构侵蚀与漂移。
- 学习路径：方法论层 L 域段。
- 案例：`CAS-X-04` 网申 v2 深度重构、`CAS-X-08` 插件深度分析。

### 3. 识别并治理技术债
- 触发问法：技术债有多少、怎么量化、先还哪一笔、要不要停止偿还。
- 应读节点：`ESS-L-02` 技术债本质 → `MTH-L-03` 技术债象限与偿还策略 → `TEC-H-02` SQALE → `TEC-H-03` 技术债量化指标 → `TEC-F-02` 需求技术债 → `TEC-H-01` SonarQube 静态分析。
- 组/视图：GCC-P 横切·技术债；决策矩阵 03 §2 横切覆盖。
- 学习路径：横切主题 P（技术债）。
- 案例：`CAS-X-05` preset 通道耦合分析、`CAS-X-15` Open Code Review 图谱。

### 4. 做架构评审 / 设计裁决
- 触发问法：这套设计行不行、风险在哪、评审要看什么、有没有更好的备选。
- 应读节点：`MTH-G-02` 质量属性场景与 ATAM → `MTH-G-06` 效用树与敏感点权衡点 → `MTH-G-01` 架构决策记录 → `ESS-O-02` 架构即权衡 → `MTH-M-06` 质量属性权衡决策。
- 组/视图：GD-G 架构设计；分层视图 01；决策矩阵 03。
- 学习路径：方法论层 G 域段。
- 案例：`CAS-X-08` dsh-manager 设计问题裁决、`CAS-X-13` 商业 Agent 架构逆向。

### 5. 建立多维权衡选型矩阵
- 触发问法：多个方案怎么比、用哪些维度、覆盖还是精度优先、成本怎么算。
- 应读节点：`MTH-O-01` 覆盖与精度的不对称权衡 → `MTH-O-04` 能力-成本-速度三角 → `MTH-M-06` 质量属性权衡决策 → `ESS-O-03` 权衡的不可消除性。

- 学习路径：方法论层 O 域段。
- 案例：`CAS-X-12` MCP 四件套选型对比。

## C. 架构与组织

- 触发问法：团队怎么分、边界和架构对不上、跨团队协作成本高、要逆向康威吗。
