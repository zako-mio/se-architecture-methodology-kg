# disclosure-allowlist.txt — 披露口径门控豁免清单
#
# 用法：每行一条，格式为「相对路径 :: 豁免词」或「相对路径 :: *」
#   - 相对路径：相对 `gate_disclosure.py --root` 的 posix 路径；
#     以 `/` 结尾表示「目录前缀」匹配（该目录下所有文件）。
#   - 豁免词：必须与门控词表完全一致（区分大小写，ASCII 词匹配时不区分）。
#   - `*`：豁免该文件（或目录）内的全部禁用词。
#   - 行首 `#` 为注释，空行忽略。
#
# 边界与纪律：
#   - 豁免只在「确有公开必要时」使用，且必须在提交说明中写明理由；
#     优先改写措辞（见 00-plan/public-wording-policy.md）而非豁免。
#   - 本文件自身被门控跳过：它是豁免登记簿，必须能够书写禁用词；
#     除本文件外，任何被扫描文件命中禁用词都会 FAIL。
#   - 词表见 gate_disclosure.py 的 TERMS（分片构造，源文件不含明文）。
#
# 示例（取消注释后按真实路径填写；下列为被注释掉的占位示例）：
# 00-plan/legacy-notes.md :: 来源受限
# 03-knowledge-map/legacy-appendix/ :: *
